## Project Overview

Wallbing is a Python-driven CI/CD pipeline that builds a browsable, AI-tagged gallery of Bing's daily wallpapers, deployed as a static site to GitHub Pages. Images are served from Bing's CDN (not hosted in the repo).

**Live site**: https://wmfrov.github.io/wallbing/

## Tech Stack

- **Build/Backend**: Python 3.11, Pillow, OpenAI API (GPT-4o-mini vision)
- **Frontend**: Single-file vanilla JavaScript + CSS embedded in `index.html` (~2,200 lines, generated by `build_gallery.py`)
- **Deployment**: GitHub Actions → `gh-pages` branch (static HTML/JSON)
- **No bundler, no transpiler, no JS framework, no test framework**

## Commands

```bash
# Setup
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Build gallery (generates index.html, search.json, browse.json on gh-pages)
python3 build_gallery.py

# Tag untagged images with OpenAI Vision + extract color palettes (requires OPENAI_API_KEY)
python3 tag_images.py           # local only
python3 tag_images.py --push    # also pushes to gh-pages

# One-time backfill for re-tagging all images
python3 enrich_tags.py --test 50   # test on 50
python3 enrich_tags.py --push      # all + push
```

## Architecture

### Data Flow

GitHub Actions runs daily: `build_gallery.py` fetches Bing API → merges into `metadata.json` → generates static site files → pushes to `gh-pages`. Then `tag_images.py --push` tags untagged images via OpenAI Vision (10 concurrent threads) and extracts color palettes via Pillow, updating `metadata.json`.

### Key Scripts

| Script | Role |
|---|---|
| `build_gallery.py` | Core build: fetches Bing API, merges metadata, generates all static output (index.html, search.json, browse.json) |
| `tag_images.py` | AI tagging via GPT-4o-mini vision + color extraction. Concurrent (10 threads), resumable via `tags_progress.json` |
| `color_extract.py` | Extracts 5 dominant colors using Pillow median-cut quantization. Filters near-black/white pixels. Maps to CSS color names |
| `enrich_tags.py` | One-time batch re-tagging script with improved prompts |

### Generated Files (on gh-pages)

- `index.html` — Full gallery with embedded JS/CSS
- `metadata.json` — All image metadata with tags and color palettes
- `search.json` — Compact client-side search index
- `browse.json` — Category filter aggregation with counts

### Frontend (embedded in index.html)

The gallery JS supports: multi-dimensional filtering (AND across dimensions, OR within) with collapsible filter panel, client-side full-text search via `search.json`, 16-cell color spectrum grid, color similarity search (click lightbox swatches, Euclidean RGB distance), geo dropdown with region grouping, lightbox with palette swatches and navigation, and lazy-loaded image grid.

### Color System

16 color buckets (Red, Coral, Orange, Gold, Yellow, Lime, Green, Emerald, Teal, Cyan, Sky, Blue, Purple, Pink, Brown, Gray) defined in `COLOR_BUCKETS` in `build_gallery.py`. Each bucket aggregates multiple CSS named colors into a single filter cell. 140+ CSS color names mapped via `color_extract.py`.

### Tag Schema (per image in metadata.json)

`subject` (array, up to 3), `season`, `country`, `region`, `time_of_day`, `mood`, `ai_description`, `keywords` (10-20), `search_text`, `color_palette` (5 colors with hex/name/weight).

## CI/CD

GitHub Actions workflow (`.github/workflows/download-bing-image.yml`): runs daily at 3:30 PM UTC. Requires `GITHUB_TOKEN` and `OPENAI_API_KEY` secrets.

## Branches

- `main` — Python source code
- `gh-pages` — Generated static site (force-pushed by build scripts)
